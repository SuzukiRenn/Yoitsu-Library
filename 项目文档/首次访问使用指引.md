# 首次访问使用指引

- 首次打开有「推荐」入口的书单页面时，显示两步指示：推荐一本书、参加推荐活动。推荐表单、反馈页和管理页不弹出。
- 每步仅一句提示；支持「跳过」、完成和 Esc 退出。引导不自动跳转、不提交推荐。
- 使用浏览器本地存储 `booklist.guide.seen.v1` 记录已完成或跳过，不绑定匿名身份、不保存到服务器。不同浏览器或清除站点存储后会再次出现。已使用过网站的浏览器在此功能上线后也会出现一次。
- 本地存储不可用时尝试会话存储；两者都不可用时不自动展示，避免反复打断。
- 使用原生 modal dialog 限制键盘焦点，退出后恢复焦点。指示位置随窗口尺寸和滚动调整，手机端不沿用桌面固定坐标。
- 验证：`node scripts/test_first_visit.mjs`。浏览器核验两步切换、390px 手机布局、完成后刷新不重复显示。
