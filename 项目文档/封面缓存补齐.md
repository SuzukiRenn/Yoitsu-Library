# 外链封面缓存

封面图片保存在数据目录的 `covers/`，书目数据库保留原始来源网址。页面优先使用已经校验的本站缓存，缓存缺失时仍保留来源地址，不把占位图当作封面。网页请求不触发外站下载。

允许的来源仅包括文库 8 和哔哩轻小说已知的封面路径；拒绝任意域名、凭据、端口、查询参数、重定向及不匹配的作品编号路径。下载文件继续校验格式、尺寸和大小，禁止 HTML、SVG、截断文件和过大图片进入缓存。

批量补齐命令：

```powershell
python scripts/cache_external_covers.py --database <现有数据库> --cache-dir <covers目录> --checkpoint <独立进度目录/state.json>
```

数据库使用只读连接。范围为作品当前实际使用的封面和主题快照封面，包含人工覆盖的地址；已缓存文件跳过，文库 8 原有采集命令仍只处理文库 8。新命令依据各来源的 robots 规则并至少间隔两秒请求，不跟随重定向，遇到拦截、无效图片和不可访问来源会记录失败而不绕过。

进度文件记录 `status`、`counts`、`processed`、`remaining`、`current_url` 和逐项结果。相同命令可继续未完成任务；失败/拦截项不会自动循环重试。在进度目录创建 `STOP` 可暂停；恢复前由操作者明确移除该标记。原有成功封面不删除，不修改书目、推荐或账户记录。服务器以独立任务运行，不给网页应用容器增加外网访问权限。
