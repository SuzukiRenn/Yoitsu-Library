# 搜索高亮与阅读偏好

匿名版与身份版共享浏览体验；不改变检索、计数、写入和排序规则。

## 搜索匹配高亮

公共书架、主题推荐的卡片和紧凑列表只在可见的书名和作者上标出实际匹配文字。公共书架遵循现有 SQLite ASCII 大小写语义，主题遵循 Python casefold，包括多字符映射；活动始终使用其快照字段。别名仍可检索，只有别名命中而可见字段不匹配时不伪造高亮，不增加别名说明。

初次渲染、分页及局部搜索/返回/定时刷新使用同一服务端高亮；局部刷新只同步对应可见字段的子节点，不替换卡片交互节点。文本逐段转义，不拼入用户可控 HTML，也不使用搜索词构造正则表达式。清空搜索移除高亮。

## 现有外观设置

继续使用当前浏览器的 `yoitsu:appearance:v1`，兼容旧的明暗和主题色配置，新增 motion 和 hideHeat 字段。所有选项均可实时预览，保存持久化；取消、Escape 和离开页面还原已保存配置。保存后跨页面和同源标签页同步。

动态效果“默认效果”遵循系统偏好，也可选择“减少动效”。用户主动减少或系统要求减少时，取消非必要卡片移动、渐入、视图/页面过渡和回顶平滑滚动；保留当前数据显示、排序、自动刷新、焦点和成功失败状态。切换为减少时会清理已有 JS 动画；不提供覆盖系统偏好的强制动画开关。

“隐藏推荐点赞数字”默认关闭，开启后覆盖公共书架与主题推荐的卡片、紧凑列表和作品详情中的推荐人数与作品点赞数。操作按钮、本人已操作状态和各类排序保持；理由赞同数、理由条数、标签计数及分页仍显示。读屏按钮名称也隐藏热度数字；后台计数继续更新，关闭隐藏时恢复最新数字。此选项只是显示偏好，不能用于数据保密。

## 验证

后端覆盖可见字段、重复匹配、别名仅命中、安全转义、活动历史快照、大小写语义与分页。
前端覆盖旧配置兼容、初次绘制、系统偏好、预览取消保存、跨页和跨标签页、存储失败、有效动效偏好，以及隐藏后统计更新与读屏名称恢复；另使用独立样例库进行浏览器验收。
