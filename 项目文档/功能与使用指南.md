# 功能与使用指南

更新于 2026-10-26。本文按当前代码整理读者与管理员流程；发布状态见[项目现状与版本差异](项目现状与版本差异.md)，历史设计材料不直接替代使用规则。

## 定位与参与身份

ヨイツ図書館（Yoitsu Library）用于共同荐书与发现作品。书目资料是阅读参考，推荐理由是自愿分享；推荐、作品点赞、理由赞同各自计数，公共书架与每期主题之间也独立统计。网站不提供小说正文阅读或下载。

本分支是匿名版 `main`。贡献权限由当前浏览器的匿名 Cookie 识别，管理员另行登录。清理 Cookie、换浏览器或使用无痕窗口不会自动继承原操作权限；本站不按姓名猜测贡献归属。

## 浏览、搜索和筛选

1. 在“公共书架”浏览当前有效推荐；“主题推荐”进入本期，或通过“回顾往期活动”查看历史主题。
2. 在搜索框输入书名或作者，停止输入约 300 毫秒后自动搜索；中文输入法组词完成后再搜索。清空按钮会立即恢复未搜索状态，其他筛选条件继续保留。仍可使用搜索按钮或 Enter。
3. 点击作品作者会搜索该作者并保留搜索框文字；点击作品标签会选中该标签筛选。书架内采用局部更新及卡片重排，普通链接、浏览器后退和新标签打开仍可用。
4. “筛选”包含“我的记录”和标签。“推荐过 / 点赞过”仅匹配本人在当前范围内仍有效的记录，同时选择取交集；不是包括已撤回操作的长期收藏。
5. 标签默认“全部符合”，可改成“任一符合”。关键词与个人记录条件仍必须满足。标签数量是该板块覆盖作品数，按覆盖数降序展示；未选标签每批 12 个，可加载更多，查找针对全量标签。
6. “清空标签”保留搜索和个人记录；“清空筛选”同时清除标签和个人记录，仍保留搜索、排序和每页数量。新搜索或筛选返回第一页。

公共书架支持推荐最多、点赞最多、最新加入及全部时间、近 30 天、近 7 天；主题使用本期独立排序，不接受公共时间范围。公共书架可按别名找到作品；主题搜索使用快照书名和作者。可见书名与作者的匹配片段会高亮，只有别名命中时不伪造可见高亮。列表只搜索当前范围内的有效推荐，推荐表单的候选查询则面向正式书库。

## 视图、随机和连续浏览

悬浮工具按外观设置、视图切换、随机推荐、回到顶部排列；只在适用页面显示对应工具。桌面沿主导航右侧边缘悬浮，不占正文排版；回顶在滚动后出现，并尊重减少动效设置。

卡片与列表视图在公共书架、主题推荐间共用偏好。列表保留小封面、书名、作者、标签和互动按钮，隐藏理由预览；完整理由在详情页查看。切换不改变筛选集合、排序、页码或统计。

公共范围随机从整个有效公共书架选书，主题范围只从当前主题选书；不受当前搜索、标签、个人记录或分页限制。详情页随机排除当前书，空集合或仅剩当前书有明确提示。

从书架卡片进入详情后可按原筛选集合上下本浏览，跨页但不循环；本轮顺序在当前标签页暂存，跳过失效候选，不把后来新增作品插进队列。页面内返回恢复原搜索、筛选、页码与阅读位置。直接访问或随机进入无有效来源时，不显示这套顺序导航。

## 推荐、理由和撤回

- 先搜索正式书库并选择作品；确实没有时填写新书资料。相似候选必须核对，不能把译名差异直接判成新作品；受限或待核查作品不立即进入公开列表。
- 推荐数表示有效共同推荐人数；作品点赞独立，理由可留空。写公共理由前须先推荐该书，编辑权限按本版参与身份校验。
- 理由中输入 `/` 后键入书名或别名，从候选点击或上下键、Enter 选中，生成可点击引用块。普通书名不会自动变成引用；引用本身不会推荐或点赞目标。
- 勾选含剧透后，阅读处先显示“含剧透”；悬浮提示“查看剧透”。点击按钮后原位显示正文，不开浮窗，不把卡片拉长。普通长理由仍支持折叠；列表视图不显示理由预览。
- 点击理由赞同只影响该理由，不影响作品点赞或推荐。详情里的理由赞同数不会被“隐藏推荐点赞数字”隐藏。
- 撤回最后一份推荐时先显示确认，取消不写入；确认后服务端重新核对实际范围与记录。归零只结束该范围本轮互动，不把其他板块的贡献一并撤销。手工作品退场后再次推荐可能需要重填资料。

匿名版由管理员选择“同时推荐到公共书架”或“仅推荐到本期活动”，默认前者。首次有效参与后归属永久锁定；待核查申请保存提交时归属，审核时已改变则要求重新核对。仅本期不自动增加公共推荐或公共理由，仍可单独参与公共书架。

## 外观和浏览偏好

外观设置提供跟随系统、明亮、深色和五种柔和主题色。深色基础为蓝灰色，强调色单独选择；动效选项叫“默认效果 / 减少动效”，默认效果仍尊重系统减少动态效果偏好。

“隐藏推荐点赞数字”覆盖两板块卡片、列表和详情中的作品推荐数与点赞数，保留操作状态、理由赞同、理由条数、标签数和分页；数据与排序不变。此设置只是显示偏好，不是数据保密措施。

外观可即时预览，保存后仅写当前浏览器同源存储；关闭或取消回到已保存配置。视图偏好同样可跨板块复用。这些偏好不会跟账户跨设备同步；浏览器限制存储时按页面提示降级。

## 资料与版本

作品详情展示分类、版本、作者、简介、来源更新等已有资料。明确 Web 版才在书架与选书候选的书名后显示 Web 标记，详情标题不重复标记。明确文库分类显示文库版；仅有小学馆、集英社、一迅社、讲谈社等出版社证据时显示出版社，不把它自动当成 Web 或统一文库开本。无法确定时显示其他类型。

Web 和文库可分别作为作品保留；只有同作品、同版本且证据充分时才排重，书名相近不是自动合并依据。主题的标题、作者、标签和封面遵循快照；审核获批的新快照与正常推荐保存同一套完整资料，已有历史快照不自动重写。

## 管理、反馈与分享

管理员使用独立 `/manage/` 后台，负责活动、资料核对、待核查、理由治理、合并与撤销、审计和反馈处理；普通读者不会因登录获得管理员权限。

活动可创建、安排、开始、暂停、恢复、结束或取消，按状态限制修改。当前正式安排/运行时段不能冲突，不提供多个重叠主题并行运行。结束后保留历史，不把当前书目资料变动反写成历史资料。

主题总结可由管理员导出 PNG 或打包图片；图片展示书目信息和理由数量，不导出理由正文或剧透文字。页面底部“问题反馈”可报告资料错误或不当内容；处理回复仅提交者可见，管理员保存反馈状态不会自动改变推荐、点赞或作品。

## 维护入口与限制

采集详情、重复比对、人工审核、入库预览、正式增量入库、封面缓存是不同步骤。审核页保存结论不等于已入库；只有最终确认新增的候选才入库并下载封面，重复条目排除。运行数据库、审核结论、抓取页面、日志、Cookie、密钥和封面缓存均不随 GitHub 源码分发。

本机草稿功能已撤回，不提供推荐退出自动保存；封面大图因清晰度条件不足未提供。不要把讨论过的候选功能当成已上线能力。
