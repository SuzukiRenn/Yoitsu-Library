# 公共书单时间范围排序

2026-10-21，身份版独立工作树 `codex/identity-booklist`。仅公共书单启用时间范围；活动列表、活动统计和作品详情计数保持原规则。没有修改匿名版工作区、服务或数据，没有部署。

## 参数与计算口径

公共页面 `/` 和列表接口 `/api/v1/public/works/` 共用 `period` 参数：

| 参数 | 含义 |
| --- | --- |
| `all` | 默认全部时间，截止本次请求时刻。 |
| `month` | 本次请求时刻向前滚动 30 天。 |
| `week` | 本次请求时刻向前滚动 7 天。 |

以单次请求的同一个服务器时间为基准，贡献记录的 `created_at` 必须大于等于范围起点、小于等于请求时刻。时间范围不是自然月或自然周。未来时间记录不参与排名。未知值、空值或重复 `period` 均返回 400，包括 `sort=newest&period=bad`。

仅统计目前有效的公共推荐和公共点赞：已撤回/取消、失效或归档的记录不参与排名。撤回后重新推荐会产生新记录，以新记录创建时间计算；手工作品退榜后的资料重填规则不变。

排序规则：

1. `recommendations`：范围内有效推荐数降序、同范围有效点赞数降序、`public_added_at` 降序、作品 ID 升序。
2. `likes`：范围内有效点赞数降序、同范围有效推荐数降序、`public_added_at` 降序、作品 ID 升序。
3. `newest`：按原有 `public_added_at` 降序、作品 ID 升序，不使用时间范围；合法的范围参数归一为 `all`，页面隐藏范围选项。切换到此排序的链接显式携带 `period=all`。

近一周和近一个月仅显示主排序指标在范围内大于零的作品。先完成标签过滤、全局排序和主指标筛选，再分页；分页总数是当前范围下符合条件的作品数。标签候选及其计数保持原有全书单口径。

卡片上的推荐数和点赞数仍是当前有效记录的累计数量，并非短期榜单分数。接口返回规范化的 `period`，原有卡片字段的含义不变。按最新界面要求，页面只展示三个简洁范围选项，不显示整行计算说明；计算细节保留在本文档。

活动页面和活动列表 API 不接受 `period`（包括 `all`），传入返回 400；其排序链接不添加该参数。

## 页面联动

排序和时间范围切换复用现有 HTML 局部刷新、请求取消及过期响应保护，更新地址栏并支持浏览器前进/后退。切换保留标签和每页大小，并回到第一页。同步更新范围选中状态、范围组的隐藏状态、标签表单隐藏值和清除筛选链接；即使标签集合没有变化也同步链接。普通链接和 GET 表单保留无 JavaScript 的浏览路径。

账户导航的圆角样式和作品卡片隐藏推荐者名单的改动保留；推荐者归属数据、消息通知、活动导出及推荐生命周期不变。本功能没有数据库迁移。
