# 推荐理由剧透折叠

匿名版推荐或编辑自己的理由时，可勾选「含剧透，默认折叠推荐理由」。标记作用于整条理由，理由仍可留空；清空理由时不保留剧透标记。

公共书单、推荐活动的卡片摘要及详情理由默认只显示「含剧透」按钮，悬浮或键盘聚焦时以项目统一提示样式显示「查看剧透」。点击后按钮消失，同一位置展示理由，不打开浮窗，也不保留收起按钮。卡片仍为固定两行摘要、固定高度，完整理由可进入详情阅读；详情直接展示整条理由。普通理由继续保持原有长文折叠。

显示状态只属于当前页面中的当前理由；同一理由的自动赞数刷新保留显示状态，正文、理由身份或剧透标记变更时恢复隐藏。重新进入页面默认隐藏。赞同不会自动显示正文，标记不改变推荐、作品点赞、理由赞同或最高赞排序规则。脚本未加载时保持隐藏，可在脚本恢复后点击查看。

活动复制理由到公共书单时一并复制标记；待核查活动申请批准后同样保留标记。已结束活动保留标记且不可编辑。活动总结预览和分享图片当前仅包含理由数量，不包含任何理由正文。

迁移 `0012_reason_spoilers` 为 Recommendation 和 PendingActivitySubmission 添加 contains_spoilers，旧理由默认普通理由。SQLite 使用原位新增列，保留既有贡献校验和审计触发器。迁移前备份数据库。API 将标记作为可选布尔字段，旧客户端省略时保留已有标记，显式 false 才取消。旧合并快照未记录该字段时按 false 比较和还原。
