# 书单搜索与浮层标签筛选

公共书单和推荐活动均支持 `q`（最多100字）书名/作者片段搜索，与重复的 `tag` 参数（最多20项，交集）、现有排序和分页组合。提交新搜索或标签筛选会回到第一页。搜索仅限当前可见且有效推荐的书单，不能搜索出未推荐、隐藏或已撤回的作品。

公共书单按当前显示书名、有效别名和显示作者搜索，包括管理员覆盖值及手工作品作者；活动按活动快照书名、作者和标签搜索，保持历史活动含义。标签旁数量为该公共书单/活动内的作品数，不随当前搜索关键词或已选标签改变。

搜索栏与标签筛选保持紧凑；手机窄屏搜索框独占一行，按钮不拉伸。排序入口位于上方“上一页 / 下一页”左侧，原生 details 面板内保留三种排序，公共书单同时提供时间范围；选项即时更新，可组合选择，点击外部或 Escape 关闭。面板与分页内容分离，空结果及轮询更新仍保留排序入口和焦点。标签使用原生 details 浮层，在页面上方覆盖显示，不增加书单高度；支持查找标签、多选、清空选择和应用筛选，Escape或点击外部可关闭。无JavaScript时仍可展开和GET提交。

局部更新复用书单排序刷新：保留计数更新与卡片移动，取消过时响应，历史返回恢复关键词和标签。后台轮询不覆盖用户尚未提交的输入和标签选择。关键词及筛选条件保留在排序、时间范围和分页链接中。

实现：booklist/shelf_filters.py、public_booklist.py、activities.py；共享模板 shelf_filters.html；static/tag-filter.mjs、shelf-sort.mjs、live-shelf.mjs。
