# 阶段 3 本地候选与目录验收

2026-10-19（Asia/Shanghai）。结论：阶段 3 本地查询部分通过验收；不是完整阶段 3 或生产发布验收。用户补充要求界面只保留最低限度文字，已同步到独立界面约定并落实到首页、候选、空状态及详情。

## 交付

新增本地候选服务、搜索/详情 GET API、书库首页与作品详情页，具备原文/确认别名精确、规范化、前缀/包含和有界模糊候选。不同作品同名不合并；不做自动关联，不写推荐或公共收录。标题覆盖优先，主动清空作者/简介/封面生效；原始输入不自动变成别名。候选、详情和首页共用可见性约束，隐藏、待核查、合并非正式记录均不可通过 ID 或别名查询。

标签展示应用停用、合并与单来源/作品级治理规则。封面不自动改写 HTTP 为 HTTPS，不代理抓取；当前三份样本使用占位。所有作品文本作为纯文本，模板转义、动态内容使用 textContent；HTML 页面设置 CSP，拒绝脚本/对象注入。查询输入及参数严格校验，300 码点、候选数量和请求限流独立生效。

界面删除宣传标题、标语、英文装饰、页脚口号、重复提醒及占位文字装饰，直接呈现搜索和作品；只保留名称、数量、收录状态、字段及必要错误信息。保留屏幕阅读器标签和键盘导航，不为了减少视觉文字去除可访问名称。

## 真实验证

- 最终全套 **96 个测试通过**（原 77、新增 19），证据 `.runtime/catalog_verification/20261019_102715_37ab64af/all_tests.log`；该运行自检、迁移、模型漂移、三份离线样本导入均通过，无新迁移。旧的 94 测试和一次 95 测试失败记录保留，不改写为成功。
- Node 检查 5 个前端控制场景：迟到响应不能覆盖新查询、取消、码点上限、HTTP 错误、断网。中文输入、实时一个候选、清空恢复三份最近入库、作品链接跳转及详情内容在真实内置浏览器验证；原生操作系统输入法组合过程未手工验证，不能把填入中文等同于原生 IME 验收。
- 桌面无横向溢出，390 像素手机布局为单列且无横向溢出，手机详情同样通过；临时视口已恢复。截图及观察记录在 `.runtime/catalog_verification/20261019_102002_66925f06/`：catalog-desktop.png、catalog-mobile.png、work-mobile.png、ui_checks.json。该目录预览库只含三份去敏来源样本，与开发/生产库独立。

浏览器检查发现 Windows MIME 配置将 .mjs 返回为 text/plain，模块未执行；已在进程内固定 JavaScript MIME 并增加真实静态响应回归，不修改系统注册表。初版静态响应测试在数据库事务类里关闭 FileResponse，触发 request_finished 关闭测试连接，导致后续两个用例失败；现移到无数据库事务的 SimpleTestCase，最终全部通过。两项均依据实测修复。
