# 月度推荐与独立推荐页修正验收

## 问题与结果

阶段 4 已交付公共推荐，但遗漏月度活动的实际页面和参与服务，并擅自把推荐做成弹窗。已有 Activity / scope 字段只能证明数据结构预留，不能证明用户可以区分和使用两类推荐。本轮根据用户纠正补齐入口和参与流程，不再沿用弹窗设计。

- 导航为公共书单、月度推荐、推荐。月度入口按本期、待开始、往期分组，单期独立展示名称、主题、状态、上海时区起止和本期快照/统计。
- 公共推荐页 `/recommend/`；活动推荐页 `/activities/<id>/recommend/`。页面明确显示提交范围，理由编辑也是独立页面，站点已移除推荐弹窗 DOM。
- 输入书名自动查询本地数据库候选，显示标题、作者、对应范围的推荐状态/人数和本人状态，选择后补全标题。已有公共推荐者通过 +1 追加推荐，已推荐者可保存自己的理由。未选候选须确认另建；查询失败或未完成时不能当作没有候选直接提交。提交时仍在事务内复核同名/别名和可见性。
- 公共推荐人数、公共点赞、活动推荐人数、活动点赞独立。活动提交只确保公共收录，不增加公共推荐关系或任何赞。活动理由默认不复制，明确勾选后在无公共理由时复制，不覆盖已有内容。
- 活动参与实现推荐、编辑、撤回、点赞、取消和理由分页；普通写入须进行中且未到截止，暂停和往期只读。零贡献退出，旧链接点赞不能唤回，重新推荐复用快照；来源更新不改变快照。
- 管理员活动创建、修改/延期及状态转换 API 使用独立管理员会话和原子审计。安排/开始/延期检查时段冲突，暂停占时段，提前结束释放剩余窗口；终态不可重开。`advance_activities` 命令和活动访问/写入前补处理已到期事件，分别记录业务生效/实际处理时间，跨完整时段直接结束不补时。
- 迁移 0006 新增待核查活动申请及数据库追踪，隐藏同名未知身份保留申请和归属，不伪造有效推荐/快照，不产生公共 +1。后续审核不能自动回填过期活动参与。
