# 推荐查重禁止绕过修正

用户明确指出：已有别人上传的作品不应再通过上传新作品产生重复。此决定取代阶段 4 及独立推荐页设计中“用户确认同名不同作品后另建”的普通入口；历史文档是当时实现记录，不再作为当前放行依据。

公共和活动推荐页删除“作为新作品提交”复选框。输入得到候选后必须先选择已有作品，再通过 +1 追加推荐或保存已有理由；没有候选时才允许提交新书名。快速提交仍需等候选检查完成，查找失败时停止提交。

服务端在同一写事务内重新查询当前标题、有效别名和本地候选，未选作品 ID 且发现候选返回 409，不创建替身作品，不留下部分推荐、理由、快照或赞。兼容旧客户端保留 `confirmed_unmatched` 布尔字段，但不再用于放行，旧客户端传 true 仍不能绕过。该规则也覆盖规范化标题和部分书名候选。

候选只是可能匹配，不据此自动关联或合并。确属不同作品但无法在普通流程确认的，停止提交并交管理员核查，不要求用户选错作品。隐藏同名未知身份仍遵守已确认 D7 的待核查例外，核查前不公开、不计推荐，不把待核查当作公开许可；可信隐藏作品 ID 仍拒绝。
