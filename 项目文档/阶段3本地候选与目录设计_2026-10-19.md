# 阶段 3 本地候选与目录设计

本轮交付阶段 3 的本地部分：候选搜索、可见作品详情及可操作的查找页面。不启动外部采集或付费 AI，不把只读选择冒充已提交推荐；贡献写入、新建前复查和 AI 接入按后续阶段实现。继续使用现有 Django/SQLite、GitHub 与租用服务器方案。

用户明确要求最少界面文字：仅保留名称、搜索、数量、作品字段及必要错误状态；删除标语、装饰英文、引导性口号、页脚文案和重复提醒。首页直接显示搜索与作品，压缩顶部留白。后续页面同样遵守，不重新加入宣传式文案。

## 查询与身份

先匹配当前显示书名与有效已确认别名，随后 NFKC/casefold 规范化匹配，再提供前缀、包含、模糊候选。规范化忽略标点和空白，保留符号；用于找候选，不作为自动身份关联证据。显示标题遵守覆盖优先级，已匹配作品的原始输入不自动参与别名搜索。完全相同的标题或别名可以对应多个作品，结果只按作品 ID 去重，不自动选中。

不新增持久索引或结果缓存，避免导入、覆盖、别名撤回和治理状态产生过期缓存。按可见作品及有效别名读取最多 20000 个检索词，超过则明确返回 503，不以截断集合宣称没有候选。模糊比较只对字符重合预筛后的最多 200 个词执行；规范化查询至少 3 字符、查询及候选规范化长度不超过 600、长度比至少 0.5、字符集合 Dice 重合度至少 0.4、SequenceMatcher 比例至少 0.65。较长的规范化字符串仍可做精确/前缀/包含匹配。这些是保守工程初值，没有全站准确率保证；后续根据样本调整。结果默认 10、最多 20，以匹配等级、相似度、作品 ID 稳定排序。

## 可见性与字段

统一排除 hidden_at 非空、review_status=pending、merged_into 非空记录。隐藏作品及其别名不参与匹配，也不能通过详情 ID 绕过；无权访问与不存在均为 404。目录可包含尚未加入公共书单的来源作品，明确返回 is_public，不混作公共列表；D12 公共排序和标签计数在公共书单阶段实现。

只输出显示标题、作者、简介、可安全展示的封面、来源编号、公共收录状态和可见标签等明确字段，不输出匿名身份、治理原因、原始输入、覆盖标记、审计或来源原值。字段覆盖为空必须生效。标签只显示有效、启用、未合并且不受作品级禁止的关联；来源级抑制不影响独立用户/管理员关联。

当前 HTTP 来源封面不擅自升级协议、不代理下载，页面使用本地占位样式；合法 HTTPS 封面方可加载，并禁用 Referrer。缺少封面不影响候选。详情文字按纯文本转义，不渲染导入 HTML。

## API、页面与验收

GET /api/v1/catalog/search/?q=...&limit=...；GET /api/v1/catalog/works/<id>/；首页为查找页面，/works/<id>/ 为作品详情。拒绝重复、未知参数及超长输入，300 码点上限延用共享文本口径。按实际 REMOTE_ADDR 做搜索 60/分钟、目录读取 120/分钟的独立限流，不信任客户端自填转发头。应用匹配服务不另存原始查询；开发服务器/代理访问日志可能含查询串，部署阶段需确定日志脱敏口径。

输入时防抖、处理中文输入法组合事件、取消旧请求并防止迟到响应覆盖当前结果。采用真实链接及可访问状态提示，无脚本时仍可提交表单搜索。验证精确/别名/规范化/缺字错字、同名不同身份、隐藏/待核查/合并、归档别名、治理标签、字段覆盖、参数与限流、HTML/JS 注入、输入法与请求竞态，以及真实浏览器页面交互。使用独立本地验证库和去敏样本；不写开发/生产库。
