## 设计与历史验收

项目总规范、阶段0至阶段4设计和验收、月度推荐修正等原始材料继续保留在本目录，文件名不变。需要追溯某项决策或测试时，再按阶段和日期查看。当前功能入口、可执行脚本与最新采集规则优先看上面的专题文档。

维护文档时优先更新已有专题入口，避免为同一个操作流程反复增加难以检索的文件；提交说明使用简洁中文，写清实际改动。
