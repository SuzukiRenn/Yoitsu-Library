# 身份版同步阅读功能（2026-10-24）

在 `codex/identity-booklist` 合并匿名版 `7514eae`，保留独立账户、Cookie、登录校验、昵称归属、共同推荐者和通知去重。同步图书馆与板块名称、即时搜索、全部/任一标签筛选、卡片/列表切换与动画优化、主题内随机推荐、详情返回和连续浏览、外观设置、剧透理由、斜杠作品引用和 Web 标识。“我的记录”按当前账户的 principal 筛选，跨浏览器登录后归属一致，公共与主题仍独立统计。个人主页的新增 Web 标识与详情资料使用同一版本判断。

## 数据和迁移边界

- 合并迁移 `0014_merge_identity_reading_features` 连接原身份账户分支与新增剧透、引用字段；不重建互动表，不绑定历史匿名贡献。
- 已有实例使用 `scripts/publish_identity.py --update-only --increment <已批准清单>`；若没有身份版 release 和数据库则拒绝启动，不执行首次导入。
- 发布包只含已提交源码和已批准的新增元数据；不含本地数据库、账户、凭据或互动。
- 新增清单为 1063 部、22 个新标签，包含 435 部明确 Web 作品。清理后的展示标题与原始别名一并保留，Web 与文库不混用身份。封面沿用来源 URL，此次不批量重新下载旧封面。
- `scripts/import_catalog_increment.py` 在备份及恢复演练后原子追加元数据，使用来源 ID 判重、不复制本地主键。不覆盖已存在但内容不同的来源记录；遇到标签歧义则回滚。
- `scripts/catalog_preservation.py` 在迁移前记录所有原有表的字段、行范围和摘要，导入后、恢复服务前逐表验证旧字段值未变化，涵盖账户、会话、推荐、点赞、通知、活动、审计及旧书目。

## 验证及部署

回归同时覆盖旧匿名夹具与强制账户场景，新增账户筛选、引用/剧透/昵称共存、增量幂等和回滚保护测试；Node 脚本覆盖切换、引用、筛选、动画及账户菜单。现有预览库先备份，并在副本上演练迁移和完整增量导入。部署在服务器再次运行 Linux 回归及 Node 脚本，再停止身份版服务、备份、迁移、导入并检查 HTTPS 和新静态资源。

服务器范围保持 `/opt/shared-booklist-identity`、`/var/lib/shared-booklist-identity`、Compose `shared-booklist-identity`，入口为回环 `127.0.0.1:8444`。发布前后比较匿名容器标识、镜像、启动时间及端口，匿名实例不变才允许成功。以匹配提交的 `IDENTITY_DEPLOY_SUCCESS`、`server-receipt.json` 和增量回执为最终部署证据，本文不代替运行回执。
