# 版本资料与 Web 标识

详情页资料栏增加“版本”，与来源分类、作品状态、来源更新和字数并列。Web 版、文库版及其他类型优先读取作品 `source_metadata.edition` 的明确值 web/book/other；已有明确文库分类可兼容显示文库版。仅有小学馆、集英社、一迅社、讲谈社分类而没有明确版本值时，沿用对应出版社名称，不根据出版社推断 Web。其余无明确证据的条目显示其他类型，不把缺失文库8身份或书名相似当作 Web 证据。

仅 edition=web 在书名后显示 Web 小标识：覆盖公共与主题的卡片和列表、资料库搜索、推荐搜索候选和已选候选。服务端首屏与动态候选共用相同规则；详情页标题不重复加角标，版本在资料栏单独展示。

版本属于独立作品记录的识别资料。主题列表继续使用原快照标题、作者、标签和封面，版本按该独立作品的明确来源资料读取；本次不改历史快照、作品关联或任何互动统计。不构建自动版本关系，不批量修改分类，不变更采集与暂存审核。2026-10-24 已审核的哔哩增补清单包含 1063 部作品，其中 Web 版 435 部；入库时携带明确 edition 数据。标题中冗余的 Web 版本字样从展示标题移除，原始标题和别名保留以供搜索。服务器使用元数据增量清单导入，不上传或替换本地数据库。
