# 身份版新活动提示

主题推荐入口旁显示“有新活动”的轻量提示标签；不遮罩、不占用排版、不自动跳转或移动焦点，遵循明暗主题与减少动态效果设置。

只有已发布、未到截止时间的待开始、进行中及暂停活动参与判断；草稿、已结束和已取消活动不提示。以活动 ID 区分新活动，改名、修改主题、暂停后恢复不会重复提示。

成功进入主题推荐页面后，将该页面加载时已发布的活动标为已查看。点击后导航失败不会标记；进入后才新发布的活动仍可提醒。保持页面打开时每分钟检查一次，隐藏标签页停止轮询，恢复可见时检查。

已登录账号在服务器独立保存记录，跨浏览器登录可共用；未登录访客在当前浏览器保存，受浏览器清理及隐私模式影响。不同账号和访客不共用已查看状态。该记录不改变站内消息、推荐、点赞或活动参与情况。仅身份版提供此功能。

旧版本未保存访问记录，无法追溯此前是否已经查看。功能首次启用时，当前仍有效的已发布活动会提醒一次；此后按实际记录判断。
