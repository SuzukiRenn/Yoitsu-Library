# 限速元数据采集与首批建库

2026-10-19（Asia/Shanghai）。用户已授权推进采集工具与最多 20 部作品的小批量建库。本轮仅采集详情元数据，写入独立本地验收库；没有开放公网、修改服务器或写入正在验收的书单数据库。

## 采集工具

`scripts/collect_wenku8.py` 使用现有传输诊断、详情解析器、字段校验和事务导入服务。每批最多 20 个明确作品 ID；也支持从一页已观察到的来源目录链接中提取最多 20 个详情 ID，不使用列表标题写库，不顺序枚举未知编号。

固定 HTTPS 主机；只读 robots、允许的目录和规范详情路径。无 Cookie、无来源账号、无重定向跟随、无自动重试、不下载封面文件或小说正文。保留默认 TLS 校验；先检查 robots，再按更严格的 robots 时序和至少 15 秒间隔请求，间隔超过 60 秒停止。本机可能沿用系统代理，不能把本机成功视作服务器网络验收通过，也不把 robots 可读取视作来源方批量采集授权。

单请求上限沿用预检：robots 64 KiB、目录/详情 512 KiB、阻塞 I/O 超时 15 秒；总预算在读取块之间检查。日志只保存规范 URL、时间、状态、字节数、摘要及错误类型，不保存响应正文、Cookie、账号区域或可能泄漏连接信息的异常原文。重定向、HTTP 错误、超时、异常内容/身份或不完整详情均停止当前运行。

## 检查点与数据保护

每批独立保存于 `.runtime/source_collections/<批次>/`，忽略外部传入的数据库目录与生产环境，初始化自己的 `data/booklist.sqlite3`。状态和已解析元数据均先写临时文件、flush/fsync 后原子替换。跨批次使用 OS 文件锁，进程退出时释放锁，不靠删除“残留锁”恢复。

状态为 pending、fetched、imported、partial、failed。元数据落盘后记录 SHA-256；恢复绑定解析器、采集器、导入服务和传输代码指纹。每项使用独立短事务，不在等待网络时持有数据库事务。数据库提交后若尚未更新检查点便中断，可再次按唯一来源 ID 幂等同步；数据库写入失败保留 fetched 元数据，恢复无需重新联网。已完成条目不在普通 resume 中重抓；失败条目必须明确指定 `--retry-failed`。

来源字段、字段警告和标签沿用现有导入规则：管理员覆盖和治理保留；缺失/异常字段不清空旧资料；不自动合并同名作品。不创建推荐、点赞、公共理由或公共收录时间。summary 明确区分完整、部分成功、失败和待处理，并检查数据库完整性及外键；退出 0 不代表所有可选字段无警告。

## 使用

```powershell
# 新批次，最多 20 部明确 ID；程序输出 BATCH 路径。
.\.venv\Scripts\python.exe -B scripts/collect_wenku8.py --ids 4151 3219 2951

# 将以下变量替换为程序刚输出的实际批次路径。
$batchDir = '.runtime/source_collections/实际批次目录'
.\.venv\Scripts\python.exe -B scripts/collect_wenku8.py --resume $batchDir

# 明确重试失败条目，不自动重试。
.\.venv\Scripts\python.exe -B scripts/collect_wenku8.py --resume $batchDir --retry-failed

# 完成批次后，在该批次原数据库内刷新同一组 ID。
# 新资料仍需重新通过完整性和身份校验；更新不增加重复作品。
.\.venv\Scripts\python.exe -B scripts/collect_wenku8.py --resume $batchDir --refresh
```

`--max-items 1..20` 限制本次处理项数。部分运行保留 pending，不报整批成功。`--refresh` 只允许已全部 imported/partial 的批次；刷新中断后使用普通 resume。尚无长期自动采集调度、全站遍历、生产导入或跨批次汇总功能。

## 本轮实测及解析修正

本机 robots 与详情 4151 均完整返回，但作者导航出现未加引号且含等号的查询参数。原词法规则把等号当作属性值终点，误判 `unverified_attribute_syntax`。修正仅允许完整、无引号值内的等号；不放行引号/尖括号等边界，不将无引号 href 中的缺分号实体错误视为可忽略。正文实体错误、结构错误、截断和诊断洪泛仍受原规则保护。原两个旧解析器保持不变。

来源详情页实际提供了最近更新目录入口，但请求该目录返回 HTTP 302，采集器停止且未跟随。后续首批采用三个已有样本 ID 加该公开详情页实际列出的九个详情链接，共 12 部明确 ID；没有试探其他受限目录或搬运登录会话。

验证包含断点、无重复导入、显式失败重试、错误页/截断不入库、规则拒绝/长间隔、网络异常脱敏、元数据缓存篡改、数据库中断的无网络恢复、治理覆盖保留、锁互斥释放和命令行隔离目录初始化。来源访问失败的证据和首部已入库的批次均保留在忽略的 `.runtime/`，不上传原始来源数据。
