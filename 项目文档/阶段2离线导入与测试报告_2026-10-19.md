# 阶段 2 离线导入与测试报告

日期：2026-10-19（Asia/Shanghai）。结论：阶段 2 的离线小样本导入验收通过，可以准备首次 GitHub 上传；在线采集、DeepSeek 调用和生产部署尚未验收。

## 实现范围

复用两个未修改的旧解析器，在 integrations/wenku8 新增无网络适配器；新增逐项事务导入、批次/项目/追加式尝试记录、断点恢复、失败重试和迁移 0004。可信来源 ID 和标准标题是硬门槛；其他字段逐项记录明确空、未获取、解析失败、无效与原值。源字段同步保留管理员覆盖、原始提交、公开收录时间、隐藏和审核状态。

完整标签集合才能撤销来源关联；单来源纠错、作品级禁止与标签停用均不会被重导入绕过。不同来源 ID 同名不自动合并，既有人工映射可复用。字段覆盖及抑制有内部审计服务，管理界面和完整标签合并/撤销服务仍未交付。

三份历史详情元数据（4151、3219、2951）作为去敏样本；HTML 只含已保存作品主区域，未包含脚本、表单、账号资料或正文。原始标签为纯文本，没有来源标签 ID；带 ID 的异常分支是人工测试数据。expected 目录从历史 JSON 提取六项对照字段，避免克隆后依赖未上传的历史目录。

首次上传复核：将精确暂存清单导出到 `.runtime/upload_review/` 后运行验证，证据位于其 `.runtime/import_verification/20261019_094556_097348/`；45 个测试及全部导入检查再次通过。该目录只含拟上传文件，证明运行不依赖未上传历史 JSON；其中旧文件保护计数为实际保留的两个解析器。61 个暂存文件的路径与常见凭据格式扫描未发现禁入路径或命中；三份导出 HTML 的 SHA-256 与来源证明一致。扫描范围有限，不视为绝对无敏感信息证明。样本原始空白及换行按 Git 属性保留，未为消除格式提示改动历史字节。

重要异常已修正并保留失败证据：初次手动执行暴露 manifest 指纹变量被输入摘要覆盖，已分离摘要；HTML 解析器自动补齐截断文档不能证明集合完整，现要求显式结束及无解析诊断，否则可选字段失败、不覆盖或清空旧值，并增加回归测试。输入变化必须新批次；旧调试批次不伪装为成功批次。

新增 lxml 6.1.3 由官方 PyPI 获取，Windows cp314 wheel 已通过哈希锁离线安装。Linux wheel、服务器 SQLite、实际网络可达性均待验证，不把本机成功推断为服务器成功。单元测试的故障注入与网络调用拦截不代表线上观察。
