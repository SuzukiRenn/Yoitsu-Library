# 卡片动画兼容与闪烁修复

原先CSS用:active-view-transition临时禁用普通入场动画。原生跨文档动画结束后选择器不再匹配，普通animation重新生效，导致再次入场，看似页面闪烁。改为pagereveal识别实际原生过渡后设置文档级native-page-transition标记，保持到文档卸载；在head中通过小型同源外部脚本提前监听，避免defer模块错过事件。

不支持跨文档过渡的浏览器按能力检测使用Web Animations卡片放大/返回收回，随后仍进行原生导航；保留Ctrl/Command点击、新标签、减少动态效果和动画完成超时保护。无JS保持正常链接，未引入伪SPA或HTML脚本注入。浏览器自己的加载图标不能用网页动画消除。

Node测试覆盖原生标记、提前监听、兼容进出、超时、取消、历史清理和减少动态。内置Chromium实页已核对进入/返回动画结束后普通animation为none。Firefox未在当前工具环境中完成真机实测，降级路径通过自动测试，不声称跨引擎视觉完全相同。


## 卡片与列表视图切换

公共书架和主题推荐共用约 380 毫秒的布局过渡，同一本作品的卡片、封面和标题分别匹配，位置及尺寸平滑变化。保留当前作品的滚动锚点和跨板块视图偏好，不在初次加载时播放切换动画。

不支持原生 View Transition 或快照失败时，使用约 340 毫秒的 Web Animations 位移、缩放及淡入兼容路径。减少动态效果时立即切换。快速连续切换、跨标签页同步、筛选重排、窗口缩放和页面离开会收束旧动画并清理临时标记，避免两种布局动画叠加。

测试：scripts/test_shelf_view.mjs、scripts/test_shelf_view_motion.mjs、scripts/test_shelf_motion.mjs。


## 2026-10-24 动画渲染开销优化

原生卡片/列表切换只为可见卡片及其封面、标题生成独立快照，屏幕外卡片仍参与正常布局。兼容路径与FLIP重排统一先批量读取新几何位置，再播放动画或插入退出副本，减少样式读写交错。输入防抖、动画时长和缓动保持原值。新增回归断言覆盖屏幕外快照限制和读取批次。

当前内嵌Chromium的20卡片隔离重放重复对照中，命名快照由60降至18～24；rAF帧间隔P95约33.2→16.8毫秒，超过50毫秒的间隔2→0。数据是本机特定可见视口的调度指标，不等于GPU呈现帧率，也不代表所有页面、设备和浏览器恒定流畅。首次运行波动较大，不以首次极端结果估计收益。
