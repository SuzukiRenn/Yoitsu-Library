# 项目现状与版本差异

文档核对日期：2026-10-26。功能依据当前两分支代码；以下服务器结果来自 **2026-10-25 已核验发布**，不是本次重新连接服务器做的实时健康检查。本文的文档更新只同步 GitHub，不自动更新服务器。

## 两个版本

| 项目 | 匿名版 `main` | 身份版 `codex/identity-booklist` |
| --- | --- | --- |
| 读者身份 | 当前浏览器匿名 Cookie | 注册账户，登录后恢复本人权限 |
| 浏览与交互 | 可浏览并匿名参与 | 访客可浏览，贡献与反馈须登录 |
| 个人记录筛选 | 当前匿名身份、当前板块的有效贡献 | 当前账户、当前板块的有效贡献 |
| 个人主页、账户、点赞消息 | 无读者账户功能 | 有；公开昵称，账号仅本人设置与管理可见 |
| 主题推荐归属 | 管理员可选公共同步或仅本期，首次有效参与后锁定 | 始终同步建立公共推荐，尚未移植仅本期设置 |
| 共享浏览能力 | 即时搜索、标签全部/任一、多批标签、视图切换、随机、上下本、返回位置、引用、剧透、外观偏好 | 同左，继续按账户校验写入权限 |
| 运行数据 | 独立数据库、Cookie、备份 | 独立数据库、会话、备份；不认领旧匿名贡献 |

原始 `main` 目录和身份版独立工作树不是可互相覆盖的数据副本。移植前须比较认证、公共/活动范围、生命周期和历史快照，不整树覆盖另一版。

## 已知功能边界

- 不支持重叠时段多个正式主题并行；可保留多个草稿和历史主题。
- 不提供推荐退出自动草稿；该尝试已按用户决定回退。
- 不提供封面大图入口，已有缓存清晰度不足时不人为放大或重新生成封面。
- 外观和视图偏好只存当前浏览器，不跟随账户跨设备同步。
- 隐藏数字不隐藏接口数据；减少动效不停止轮询或写入。
- Web/文库关系不能仅凭相似书名推断；不自动合并不同版本或清理历史贡献。

当前使用方式见 [功能与使用指南](功能与使用指南.md)，原阶段规范和带日期验收文档用于追溯当时设计，不能自动视为现行功能或线上状态。
