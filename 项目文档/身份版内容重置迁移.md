# 身份版内容重置迁移

此工具仅用于管理员明确授权的内容重置，不属于常规部署或日常同步。匿名版始终只读；不能用整库覆盖身份版。

## 本次约定

- 清空身份版公共书架及所有主题中的推荐、推荐理由、作品点赞、理由赞同、互动事件与互动消息，以及未完成的主题提交。
- 保留身份版账号、登录会话、管理员、邮箱验证状态、限流计数、反馈、书目资料、人工资料和审核记录；原有审计记录保留。
- 匿名版“最喜欢的三本”映射到身份版现有“十一月份推荐”，只将其标题改为“最喜欢的三本”，保留身份版当前主题时间设置。
- 匿名版往期主题单独映射或创建为历史主题，保留冻结的书名、作者、标签和简介。
- 每部公共书架作品建立一次无归属基础推荐。主题沿用现有数据模型：无理由时一次推荐，多条理由时按理由条数计推荐，不修改现有计数和查询规则。
- 理由文本、剧透标记及可用作品引用保留。推荐人、理由作者留空，不复制或推断匿名读者身份，不绑定到现有账号。
- 作品点赞、理由赞同和消息均从零开始；迁移本身不发通知。

## 执行与核验

1. 先完成代码回归、增量数据库迁移及已有数据保全核验。
2. 使用 SQLite 只读连接从匿名版创建一致快照，运行 `scripts/export_anonymous_shelf.py`。导出字段采用白名单，不包含邮箱、密码、Cookie、读者身份或历史投票。
3. 暂停身份版写入进程，创建身份版备份，并完成独立恢复演练；备份只存服务器私有目录，不提交 Git。
4. 在隔离数据库副本上运行 `scripts/seed_identity_shelf.py --preview-copy ...`。预览执行完整事务并回滚。
5. 使用同一清单 SHA-256 和预览计划摘要，在停写的真实身份版数据库上加 `--apply --expected-plan ...`。目标数据变动则拒绝执行。
6. 核验账号和会话等保留表的行摘要、书目映射、每个范围的推荐和理由数量、点赞归零、作者留空、引用重映射及外键完整性。
7. 恢复身份版服务并检查公网 HTTPS、登录页面、公共书架和主题 API，再生成迁移完成备份与回执。

`ImportedPrincipal` 仅标记无归属的迁入内容。随机秘密不保留、无读者账号绑定，因此任何账号都不能认领这些记录。真实读者后续推荐和点赞仍按原有流程处理。

同一清单批次一旦提交就禁止再次清理。发生错误应先检查事务、阶段回执和备份，不能直接重跑、清空队列或用旧库覆盖新数据。
