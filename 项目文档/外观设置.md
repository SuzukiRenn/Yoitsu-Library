# 外观设置

匿名版公共前台共用外观设置，入口位于视图切换悬浮按钮正上方；无视图切换的详情、表单等页面，位于随机推荐上方。沿用导航右边缘的悬浮对齐。

- 明暗模式：跟随系统、明亮、深色；默认跟随系统。
- 主题色：原色、青苔、雾蓝、藕粉、暖棕；不提供自定义颜色或圆角。
- 即时预览；保存才写入当前浏览器 localStorage 的 yoitsu:appearance:v1。取消、关闭、Escape 或离开页面会收束未保存预览。恢复默认也需保存。
- 进入页面前用小型同源脚本读取已保存偏好，避免先亮后暗；系统明暗变化自动更新，其他标签页保存设置时同步。
- 设置面板打开时收到另一标签页的设置，不覆盖正在预览的选择；保存使用当前选择，关闭采用最新已保存设置。
- 存储不可用时明确提示保存失败，仍可预览和取消，不宣称已保存。不会读取或写入业务数据库、身份 Cookie 或采集数据。
- 明暗样式覆盖公共书架、主题推荐、作品详情、推荐/资料编辑表单、筛选/排序浮层和作品引用等公共组件。管理后台保持自身样式。

CSS 从硬编码表面颜色改用语义变量，主按钮与文字颜色分离，以免深色模式中形成白块或浅色字配浅色按钮。按钮、常规文字和次要标签在所列配色下做对比度检查；保留系统减少动态效果和高对比度处理。

验证：node scripts/test_appearance.mjs（首次绘制与模块一致性、预览/取消/保存/恢复、系统与跨标签页同步、存储失败、文字对比度）；本地浏览器验证公共/主题、详情和推荐表单，设置按钮位置及深色背景。

深色基础面板使用蓝灰色（背景 #0f172a、卡片 #1e293b、输入框 #243247），与用户选择的主题强调色分开，避免默认深色整体偏绿。
