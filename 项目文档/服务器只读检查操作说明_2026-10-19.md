# 服务器只读检查操作说明

当前采用本机 SSH 客户端、用户手动输入密码。无需 GitHub 密码或 token，无需预先配置 SSH 别名。服务器连接信息只在本机使用，不写入代码或报告。

在本机 PowerShell 中进入项目目录，将下方 `服务器公网地址` 换成自己的地址；SSH 端口不是 22 时在 `ssh` 后添加 `-p 实际端口`，账号不是 root 时替换账号：

```powershell
Get-Content -Raw .\scripts\probe_wenku8.py | ssh -o StrictHostKeyChecking=yes -o ForwardAgent=no -o ClearAllForwardings=yes -T root@服务器公网地址 "python3 -B - --location server"
```

输入服务器密码时通常不显示字符，输入后回车。密码仅输入在 SSH 的终端提示中，不发送到聊天。此命令将已审查的本地 Python 脚本传到远端标准输入，在内存中执行；不在服务器创建文件、不安装依赖、不部署网站。最多两个请求，每次阻塞 I/O 超时 15 秒，总计 30 秒预算在块间检查，阻塞调用可能延后退出；符合条件时两次请求间至少间隔 10 秒。

返回结果为 JSON，可粘贴回当前对话；脚本不输出服务器公网地址、主机名、Cookie、原始网页或异常详细文本。`detail_http_received_metadata_unverified` 只是 HTTP 收到 HTML；其他 outcome/stop_reason 保留真实失败原因，不要通过关闭主机校验、反复重试或复制 Cookie 来改变检查结果。

新版 schema_version=2 的 requests 记录 phase、bytes_read、chunks_read、body_complete、headers_ms、first_byte_ms 和 elapsed_ms。有响应头但无首字节、部分正文后超时、完整传输可据此区分；没有新版输出时，不应从上一版缺失的字节计数猜测故障阶段。服务器暂不使用仅供本机安装环境的 `--check-metadata`。

如提示主机密钥变化，先核对云控制台上的服务器身份，不移除旧密钥或忽略校验。如提示 `python3: command not found`、密码拒绝或连接失败，将错误信息脱敏后反馈即可，不自行安装或修改服务器 SSH 配置。终端没有出现时，可在项目文件夹手动打开 PowerShell 运行同一命令。
