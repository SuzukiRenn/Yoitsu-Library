# 推荐理由中的作品引用

公共书架和主题推荐共用同一套引用输入方式。输入“/”后键入书名或别名，停顿后显示正式书库中的候选；点击候选，或使用上下键与 Enter，即可将“/书名”替换为完整书名并生成浅色引用块。没有选择候选的普通书名仍是普通文字。移动端同样支持候选选择。

## 显示与编辑

- 阅读理由时，引用块可点击进入对应作品详情；无下划线，悬浮时浅色加深。
- 编辑时引用作为整体选择、删除；保存后再次编辑仍保留引用。
- 理由仍为纯文本，按可见文字计算原有 200 字限制，每条最多 8 个引用。
- 引用不自动推荐或点赞目标作品，不建立版本关系，不改变两板块的独立统计。
- 剧透引用仅在用户主动查看剧透后展示，卡片沿用原有固定高度。

## 数据与生命周期

Recommendation 和 PendingActivitySubmission 新增 reason_references JSON 字段，保存作品编号与正文中的 Unicode 码点起止位置。服务端验证目标可见性、文字匹配、范围及重叠，不接受外部地址或富 HTML。查询结果只包含正式可见书目，不包括采集暂存区。

正文保留作者写下时的书名。目标改名不会改写原文；目标隐藏、退出正式书库或被合并时保留原文并停用链接。待核提交批准、主题理由复制到公共书架、历史主题及作品合并撤销均保留引用资料。旧客户端未提交引用字段时，仅在正文未改变的情况下保留旧引用。

活动总结图目前没有导出理由正文，因此不会额外导出引用或剧透文字。
