隐私说明

更新日期：2026年10月27日 · {% if account_edition %}账户版{% else %}匿名版{% endif %}

ヨイツ図書館用于共同荐书和发现作品。本说明介绍本站实际使用的数据、公开范围和处理申请方式。

运营与联系

本站由ヨイツ図書館站点运营者维护。隐私、账户资料和内容问题可联系 {{ contact_email }}，或查看联系与投诉。

我们处理哪些信息

    {% if account_edition %}
  • 注册、登录和账户管理：账号、昵称、密码的加密哈希、会话状态，以及推荐、点赞、理由和通知。本站不保存明文密码；注册不要求填写邮箱或手机号。
  • 公开推荐和理由可能显示你的昵称、参与信息及个人主页中的推荐和近期点赞。登录账号与会话凭据不在公开界面展示。旧匿名贡献不会自动归入新账户。
    • {% else %}
  • 浏览不需要注册。参与推荐、点赞、编辑理由和反馈时，使用随机匿名Cookie识别本浏览器的贡献与权限；服务器保存令牌哈希及相关状态。匿名不等于完全不处理数据。
  • 推荐、理由、作品资料及统计可能公开展示。清理Cookie、使用无痕模式或更换设备后，无法自动找回旧身份和编辑权限。
    • {% endif %}
  • 反馈内容、相关页面及管理员回复用于处理问题，反馈页面仅向提交者和管理员展示相应记录。请勿在理由或反馈中提交密码、身份证件或他人的私人信息。
  • 网络请求会到达服务器并携带IP地址等必要连接信息；用于连接、安全限流、故障排查和反滥用。限流键使用哈希；必要的错误与操作审计会保留，不能理解为本站不产生任何日志。

Cookie与浏览器存储

必要Cookie用于身份、登录与防止跨站请求。{% if account_edition %}读者登录有效期最长30天；{% else %}匿名身份Cookie有效期最长365天；{% endif %}管理员会话最长12小时。失效或主动退出后需重新建立相应身份。浏览器还会保存主题、明暗、视图、动效和浏览位置等偏好，这些偏好不会自动跨设备同步。你可以在浏览器中清除，但可能同时失去匿名权限或退出登录。

第三方与公开内容

本站不提供小说正文阅读或下载。书目可能来自公开资料来源；封面优先使用本地缓存。打开来源链接或加载外部图片时，来源服务可能接收到必要的网络信息，并适用其自身规则。本站当前没有接入第三方广告或访问统计SDK，也不将密码或会话Cookie用于书目资料采集。

保留、撤回与申请处理

有效贡献、资料与必要历史记录为维持书架、历史主题、审计和防止重复计数而保存，当前并非按统一天数自动删除。撤回会取消相应有效关系，不等于立即物理清除全部历史记录。过期会话、限流和幂等记录由维护任务清理；备份按最近7天及此前4个周窗口轮换，并始终保护最新有效副本。

你可以通过联系邮箱申请查阅、更正、删除或限制处理本人数据。{% if account_edition %}目前没有自助注销按钮，账户停用、注销和资料处理请通过邮箱申请；不要将密码作为身份核验材料。{% else %}匿名身份无法仅凭姓名重新认领，请保留当前浏览器，提供相关页面和记录帮助核实，但不要发送Cookie或完整令牌。{% endif %}运营者核实归属及必要保留要求后处理，并通过原联系渠道说明结果。备份不直接对外提供服务；恢复时需复核已处理的删除或限制请求，避免重新公开已处置内容。

保护与变更

本站使用HTTPS、访问权限控制、哈希校验和隔离恢复验证保护数据，但不能承诺绝对安全。本说明随实际功能更新；新增处理目的、数据类型或第三方服务时应在启用前补充说明，并在需要时取得相应同意。
